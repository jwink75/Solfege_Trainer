# Documentation Detail Retention Rule

## NEVER REMOVE DETAIL FROM BIBLE DOCUMENTS
- **Rule**: Agents MUST NEVER remove detail, simplify, or truncate sections from "Bible" type documents (such as `The Solfège Star Bible (v16.0).md`) or master agent documentation.
- **Directive**: Always append new architectural sections, release notes, and technical rationales to the document, or edit specific items that are explicitly changing.
- **Rationale**: The Solfège Star Bible serves as the permanent system of record and master architectural blueprint. Preserving full historical context, decision rationales, and quantitative parameters ensures continuity across development cycles.
