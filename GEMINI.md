# Solfège Star - Project Rules & Directives

## CRITICAL GIT PUSH DIRECTIVE
- **DO NOT PUSH TO GITHUB (`git push`) UNLESS THE USER EXPLICITLY REQUESTS IT.**
- You may perform local git commits (`git commit`) when completing tasks, but you MUST NEVER execute `git push` or push commits to remote repositories (`origin/main`) unless the user explicitly instructs you to push in their request (e.g. "push to GitHub", "push it", "push changes").

## CRITICAL BIBLE & DOCUMENTATION DETAIL DIRECTIVE
- **NEVER REMOVE DETAIL FROM "BIBLE" TYPE DOCUMENTS OR MASTER AGENT SPECIFICATIONS.**
- When updating documentation (such as `The Solfège Star Bible`), ALWAYS append new sections or amend specific items that are explicitly changing. Never simplify, truncate, drop, or remove historical context, rationale, architectural diagrams, or detailed specifications.
